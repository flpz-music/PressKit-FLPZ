# FLPZ — Electronic Press Kit

Site estático (HTML/CSS/JS, sem build) com identidade azul, slides animados e contato de booking pelo WhatsApp **+55 86 99455-6828**.

## Fluxo de trabalho

1. Edite os arquivos direto no GitHub (ou via commit na branch `main`).
2. A Vercel publica automaticamente em produção a cada push na `main`.
3. Pull requests e outras branches geram URLs de preview para revisão.

Não é necessário gerar ZIPs a cada revisão.

## Arquivos

- `index.html` — página completa: estilos, conteúdo e interações.
- `assets/social-cover.jpg` — imagem de compartilhamento em redes sociais.
- `vercel.json` — URLs limpas, sem barra final.

## Onde editar

- **WhatsApp de booking:** procure por `wa.me/5586994556828` em `index.html` (botão do cabeçalho e seção de booking).
- **Slides:** array `slides` no script no final de `index.html`.
- **Links sociais:** Spotify, SoundCloud, YouTube, Instagram e Drive no próprio `index.html`.

## Antes do lançamento

As imagens atuais são prévias; confirme qualidade/direitos e substitua por originais. Os sets WAV não são incorporados (arquivos grandes demais para servir direto na web).
